## 预检与主比较

1. 本地服务进行三次简单算术热身，必须有完整、正确输出。
2. 从已使用过的 v060 题集中，按预定哈希在每个学科×难度格选一题，共35题；单次作答、4096输出上限。此阶段仅诊断可用性，不纳入新验证集统计。
3. 主比较为140道新的 MATH train 题，每个学科×难度格4题。排除历史已用题，包括 v060 和 MATH-500；题集清单记录1137个被排除的不同题目。
4. 四个单模型均使用4096输出上限，另加 DeepSeek 2048预算对照。每组每题两次独立采样，共1400次作答；平均两次结果，不挑最好一次。
5. 所有模型显式关闭思考模式。Qwen 使用 temperature=0.7、top_p=0.8、top_k=20、presence_penalty=1.5；DeepSeek 保留先前非思考参数。原始参数与响应均留存。

只有题目、公开上下文和输出契约进入模型输入。标准答案和参考解仅由评分器读取。所有组独立作答，不进行搜索或路由学习。输出截断按预定规则计0，不挑截断题另做有利子集对比。

主要比较预先固定为 Flash−本地、Plus−Flash、Flash−DeepSeek4096、Plus−DeepSeek4096，以及 DeepSeek4096−2048。按题对两次采样平均后计算配对 bootstrap 区间，同时给出五项比较的多重比较敏感性区间。140题只适合筛选，不据此宣称1个百分点的质量非劣性。
